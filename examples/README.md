# Examples

End-to-end examples demonstrating OpenLabelServer workflows.

## Specification examples

Each published specification includes validated examples under its own directory:

- [specs/renderspec/examples/](../specs/renderspec/examples/)
- [specs/stockspec/examples/](../specs/stockspec/examples/)
- [specs/calibrationspec/examples/](../specs/calibrationspec/examples/)
- [specs/api/examples/](../specs/api/examples/)

## Integration examples

This directory will hold complete workflows that combine multiple specifications — for example, rendering a label sheet defined by StockSpec with a CalibrationSpec profile and submitting it through the REST API.

Examples will be added as the reference implementation matures.
