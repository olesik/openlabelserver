# Frontend

Vue 3 web interface for OpenLabelServer.

## Responsibilities

- Label editor and live preview
- Asset, stock, and printer management
- Calibration wizard
- Print job management

The UI must not contain printer-specific rendering logic. All layout is defined through RenderSpec.

## Status

Scaffolding only. Implementation begins in Wave 7 (Frontend) per [MILESTONES.md](../MILESTONES.md).
